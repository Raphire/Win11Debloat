# Tapeta dla trybu USB

Menu `Run.bat` pokazuje wbudowaną czarną tapetę i obrazy z tego katalogu.

Dodaj własne pliki `JPG`, `JPEG`, `PNG` albo `BMP`. Enter wybiera `default.jpg`,
jeśli istnieje, a w przeciwnym razie czarną tapetę. Opcja 0 pozostawia tło bez zmian.

Wybrany obraz jest konwertowany do BMP i zapisywany lokalnie w
`%LOCALAPPDATA%\Win11Debloat\Wallpapers`. Kopia poprzedniej tapety trafia do
`%LOCALAPPDATA%\Win11Debloat\Backups\Wallpaper`. Po przygotowaniu laptopa
można odłączyć nośnik. Nie ma dopasowywania tapet do modelu lub producenta.
